# Contributing

Pull requests adding a genuinely free or open-source freelance tool are welcome.

## Guidelines

- The tool must be free to use, or clearly labeled as "free tier of a paid product" — no placements that are secretly paid promotion.
- No affiliate links.
- One tool per line, in the most relevant existing section (or propose a new section if none fits).
- A one-sentence, honest description of what it does — no marketing language.
- If you're the maker of the tool you're adding, say so in the PR description and in the entry (e.g. "(maker)").

PRs that don't meet these are likely to be declined, not out of unfriendliness but to keep the list useful.
